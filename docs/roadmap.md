## 0. Как читать этот документ

**Блок** — единица планирования. У каждого блока есть ID (`A.1.36.01`), категория,
путь к файлу, список зависимостей, версия и статус. ID состоит из книги и номера:
`A` — API, `C` — Core, `D` — DB, `F` — Frontend, `W` — WS, `L` — Lib, `S` — Security,
`N` — AI, `M` — Mobile, `T` — Tests, `X` — Docs, `I` — Infra.

**Состояние блока** — не мнение, а факт на диске:

| состояние | значение |
|---|---|
| `filled` | файл есть и непустой |
| `empty` | файл есть, но 0 байт (заглушка) |
| `missing` | файла нет |

**Вес (`unblocks`)** — сколько блоков транзитивно ждут этот файл по графу
зависимостей реестра. Это не важность, а **рычаг**: один файл может открыть
десятки других.

**Правило приоритета:** сначала то, что разблокирует остальное и даёт сигнал
(тесты, CI), затем то, что видит человек (UI), затем эксплуатация и масштаб.

## 6. Definition of Done для одного блока

Блок считается закрытым, когда выполнено всё:

1. Файл существует и непустой (`roadmap.py` показывает `filled`).
2. Реализация соответствует разделу «Публичный API» своего блока в реестре.
3. `pnpm typecheck` и `pnpm lint` проходят без новых ошибок.
4. Есть тест: юнит для Core, интеграционный для API, e2e для UI-потока.
5. Права проверены через `rights_matrix` (`C.0.01.06`, `src/core/rights.ts`).
6. Действие попадает в `access_log` / аудит (`C.0.01.05`, `src/core/audit.ts`).
7. Статус блока в `id_2.md` обновлён (`Draft` → `Done`), версия поднята.

Пункты 3–6 сейчас не выполняются ни для одного блока: тестов нет, CI нет.

## 8. Как обновлять этот документ

```powershell
python roadmap.py                      # снимок: состояния, книги, фронт, блокировки
python roadmap.py --limit 200          # полный фронт
python check_files.py                  # сверка реестра с диском → check_files.md
```

Ритм: снимок и волны — раз в 1–2 недели, после каждой закрытой волны. Волна
считается закрытой, когда все её блоки дают `filled` и хотя бы один тест на
волну. Размер волны — не больше 10 блоков, иначе она не заканчивается.

Про сам этот файл: блок `X.0.01.08` закрыт по пунктам 1–4 (файл есть, содержание
соответствует, цифры воспроизводимы, проверка — `roadmap.py`). Статус в
`id_2.md` оставлен `Draft` намеренно: менять его — отдельное решение, потому что
610 блоков с заполненными файлами тоже числятся `Draft`.

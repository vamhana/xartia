OpenAPI 3.1 — формальная спецификация ядра Хартии 5.0
Ниже — рабочий OpenAPI-контракт. Полный (400+ эндпоинтов) в одном файле не поместится в разумный ответ, поэтому даю:

openapi.yaml — корневой файл со всей структурой, security, компонентами и примерами.

Паттерн для остальных доменов — единый, копируется по образцу.

В конце — список недоменных $ref-файлов, которые просто повторяют структуру.

Файл готов к вставке в Swagger Editor / Redocly / Stoplight.

Bundle (собрать все $ref в один файл):

Генерация клиента:

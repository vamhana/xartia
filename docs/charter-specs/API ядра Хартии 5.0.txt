API ядра Хартии 5.0
REST + WebSocket. Версия /api/v1. Формат — JSON. Авторизация — JWT (access + refresh). Все ответы содержат meta с пагинацией и audit_id.

0. Общие конвенции
0.1. Аутентификация
text
Authorization: Bearer <access_token>
Access — 15 мин.

Refresh — 30 дней.

Ротация refresh при каждом использовании.

Все запросы логируются в access_log.

0.2. Формат ответа
json
{
  "data": {...},
  "meta": {
    "page": 1,
    "per_page": 50,
    "total": 1200
  },
  "audit_id": "uuid",
  "errors": []
}
0.3. Ошибки
Код	Смысл
400	Неверный запрос
401	Не авторизован
403	Нет прав (роль/мандат)
404	Не найдено
409	Конфликт (ротация, дубль)
422	Ошибка валидации
423	Заблокировано (режим)
429	Лимит запросов
451	Недоступно по режиму (Информационная блокада)
503	Изоляция Шлюза
0.4. Заголовки
X-Request-ID — трассировка.

X-Audit-Reason — для значимых действий.

X-Idempotency-Key — для создания.

If-Match — версия (оптимистичная блокировка).

0.5. Пагинация
?page=1&per_page=50&sort=-created_at&filter[status]=active

0.6. Права
Каждый эндпоинт проверяет:

роль,

мандат,

scope (Self / Dir / All / Agg / Raw / Arch),

режим (Красный Контур / Стальной Колокол / ПТТ / Информационная блокада),

cooldown,

конфликты ролей.

Отказ → 403 + запись в access_log.

44. Ограничения по режимам
Режим	Ограничение
Красный Контур	Часть PATCH/POST ограничена; аудит каждые 14 дней
Стальной Колокол	Сроки сжаты; автоподтверждение при молчании
ПТТ	Массовая переподготовка; блокировка пауз
Информационная блокада	Шлюз изолирован → 451 на gateway/*
Квант ускорения	Таймеры, дедлайны пересчитаны
Семантическая тревога	Сигнал эскалируется в 3 часа
45. Итог
~400 эндпоинтов, сгруппированных по 43 доменам.

Каждый эндпоинт:

проверяет права,

учитывает режим,

логирует,

возвращает audit_id.

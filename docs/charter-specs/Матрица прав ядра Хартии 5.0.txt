2. Базовые правила
Всё логируется. Даже Архитектор. Даже ИИ.

Ничего не «навсегда». Любой мандат — временный.

Ротация обязательна. Нельзя сидеть в одной роли дольше срока.

Запрет на совмещение конфликтующих ролей (Связной + Совет, ОТК + Совет, Оператор + Совет).

Холодный период после мандата (равен сроку мандата).

Своя работа не проверяется. ОТК не проверяет себя. Аудитор не проверяет свой аудит.

Приватность. Персональные данные — только тем, кому положено.

Базовые блага — неприкосновенны. Никакая роль не может их отнять.

Потоки — не деньги. Нельзя обменять, накопить сверх лимита, передать.

Иерархии нет. Есть мандаты и ответственность.

Семантический Страж — вне иерархии. Его нельзя отстранить, кроме ядра.

Архитектор — бог, но с логами. Может всё, но не безнаказанно.

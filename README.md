**XartIA — рабочее пространство коллектива, где код — общее достояние,
роли выдаются на срок, а вклад виден и проверяем.**

Это не «ещё один таск-трекер». Это попытка собрать в коде социальный
механизм: задачи, проверка результата, репутация (Поток) и казна живут
по правилам Хартии, а не по настроению администратора.

---

## Что здесь происходит

Коллектив берёт задачи, прикладывает результат (PR/коммит), получает
независимую проверку (ОТК) и **Поток** — подтверждённый вклад. Роли —
временные мандаты, которые истекают и ротируются. Деньги — отдельно:
казна с полом 1.00, траты только 3 подписями из 5, Поток нельзя обменять
на власть.

В ядре два больших контура:

1. **Коллектив и операции** — заявка → участник → задача → отчёт → ОТК
   → Поток, казна, Шлюз, Совет, панели, право на пересмотр.
2. **Профессиональный паспорт** — доказательная проекция человека на
   общую решётку проверяемых компетенций. Не резюме и не рейтинг.

## Профессиональный паспорт

Паспорт — это персональная **проекция** на общую решётку, а не её копия.
Он показывает, что человек способен понимать, объяснять, проектировать,
выполнять и оценивать; на каких доказательствах это основано; чему он
может учить; какие пути развития открыты.

Ключевое:

- **Атомы** — минимальные независимо проверяемые способности. Каталог:
  54 атома в 7 кластерах + 3 профессиональных профиля (Python Backend,
  QA Automation, DevOps). Расширяется через workflow (`catalog_proposals`:
  предложение → ревью → утверждение → merge).
- **Пять независимых измерений**: Понимание (`U`), Объяснение (`X`),
  Проектирование (`D`), Выполнение (`P`), Оценка (`E`). Шкала **0..9**.
  `0` — измеренная нулевая способность, `null` — оценки нет.
  Среднее пяти измерений **запрещено**.
- **Ширина и глубина — раздельно**. Ширина = атомы с уровнем ≥4 по всем
  применимым измерениям. Глубина = `deep`-атомы (`P≥7` и `U/X/D/E≥7`).
  Не сводятся в одно число. Агрегируются по кластеру/домену.
- **Доказательства и история**. `passport_history_events` — append-only
  (триггер блокирует UPDATE/DELETE). Оценку ставит уполномоченный
  проверяющий; свою работу оценивать нельзя. Апелляция не переписывает
  историю, а добавляет события и переводит оценку в `under_review`.
- **Приватность по умолчанию закрыта**. Публичный профиль — только по
  согласию. Даже ответ «подтверждено / не подтверждено» требует
  разрешения. Журнал доступа фиксирует каждое чтение чужого паспорта.
- **Три масштаба просмотра**: Обзор → Кластер → Карточка атома. Плюс
  табличный/текстовый режим и SVG-граф (54 узла, force-directed, без
  тяжёлых библиотек).
- **Калибровка** — инфраструктура для эталонных работ (`anchor_examples`)
  и сессий (`calibration_sessions`, `assignments`, `report` с
  `needsThird` при расхождении ≥2). Без медианы оценок — только
  агрегаты и флаги.

Что паспорт **не** делает: не присваивает профессию автоматически, не
сводит человека к одному числу, не заменяет юридический допуск
(отдельная сущность `Permit`), не раскрывает уровни без согласия.

Документация: [docs/passport-implementation.md](docs/passport-implementation.md),
[docs/passport-phase3a.md](docs/passport-phase3a.md),
[docs/passport-catalog-v04.md](docs/passport-catalog-v04.md),
[docs/tech-debt.md](docs/tech-debt.md).

## Кому здесь место

- **Разработчикам** — ядро на Fastify + PostgreSQL + React; нужны руки,
  глаза и аккуратность.
- **Тем, кто думает о социальном устройстве** — Хартию можно и нужно
  оспаривать; в обсуждениях есть место философии, если она превращается
  в проверяемое правило.
- **Новичкам** — здесь **нет слабых и сильных**. Есть люди с разным
  уровнем знаний, и они им делятся. Первая задача должна занимать вечер,
  а не неделю, и рядом будет человек, к которому можно прийти с вопросом.

**Главное правило:** если что-то непонятно — спроси. За вопрос не
расстреливают и не обзывают. Ответим в меру сил, обычно в течение суток.

## Попробовать

### Если вы не программист

1. Прочитайте Хартию: <https://vamhana.github.io/hartia/charter/>.
2. Принесите её вопросы и сомнения в [Discussions](https://github.com/vamhana/xartia/discussions)
   или в [Telegram](https://t.me/hartia_5).
3. Если хотите проверить Хартию на прочность — прогоните её через любого
   ИИ и покажите, где она противоречит себе. Это ценнее, чем согласие.

### Если вы разработчик (5–10 минут)

Нужны: Docker, Node.js 22+, pnpm.

powershell
```
git clone https://github.com/vamhana/xartia.git
cd xartia
pnpm install

# инфраструктура: Postgres + PostGIS, Redis, MinIO
docker compose -f docker/docker-compose.yml up -d postgres redis minio

# схема и первый участник (Архитектор)
pnpm db:migrate
pnpm tsx scripts/ensure-architect.ts
pnpm db:migrate

# сид паспорта: 54 атома, 3 профиля, 17 направлений, 0055 + anchor'ы
pnpm tsx scripts/seed-passport.ts
pnpm tsx scripts/seed-catalog-v04.ts

# API :3000 + WebSocket :3001
pnpm dev
# веб :5173 — в отдельном терминале
pnpm dev:web
```
Проверка, что всё живо:
```
pnpm typecheck          # типы API
pnpm typecheck:web      # типы веба
pwsh scripts/ci-local.ps1   # полный локальный прогон (Windows)
```
Подробнее в CONTRIBUTING.md. Первый день хартийца:
docs/onboarding-first-day.md. Если стек не встаёт:
docs/troubleshooting.md.

Как присоединиться
Познакомиться. Discussions —
идеи и Хартия; Telegram — быстрые вопросы.

Взять первую задачу. Ищите метку
good first issue.
В каждой задаче написано: что сделать, где смотреть код и как проверить.

Сделать и показать. Форк → ветка → PR. Если застряли — напишите
в задаче или в Telegram, поможем.

Правила простые: не обесценивать чужой уровень, не приватизировать роль,
не молчать, если видите проблему. В спорном вопросе действуем по логике
и духу Хартии, а не по букве.

Стек
API: Fastify 5, TypeScript, PostgreSQL 15 + PostGIS, Redis 7, S3/MinIO

Realtime: WebSocket-каналы (src/ws)

Web: React 19, Vite, TanStack Query

Паспорт: домен src/core/passport/*, API src/api/passport/controller.ts,
9 вкладок + 15 компонентов в src/web/components/passport/,
SVG-граф без тяжёлых библиотек

Инфраструктура: Docker Compose, k3d + kustomize

Проверки: 50+ шагов CI (типы, сборка, миграции на чистой базе,
smoke-тесты 30+ контуров, включая passport-v2..v8 и catalog-v04)

Заметка про инструменты
Код открыт, и для навигации можно использовать любые инструменты — от
grep до ИИ-ассистентов. Никакой конкретный платный инструмент не
требуется: всё то же самое делается обычным редактором и терминалом.
Если используете ИИ — проверяйте его ответы; финальное понимание
остаётся на вас.

Библиотека виджетов ядра Хартии 5.0
Ниже — детальная библиотека. Каждый виджет — атом UI. У каждого: тип, сущности, поля, действия, источник данных, кто видит.
Разбито по смысловым блокам, чтобы конструктор был удобным.
1. Идентификация и паспорт
1.1. Виджет «Паспорт участника»
Тип: карточка.
Сущности: Участник, ID, Направление, Профессия, Роль, Статус, Ячейка, Геолокация.
Поля: ID, имя, псевдоним, направление, профессия, роль, статус, наставник, стажёры, дата входа, волна, геолокация (опц.), фото.
Действия: редактировать (если свои), запросить смену направления, написать, позвонить, добавить в ячейку.
Источник: реестр участников.
Доступ: все (с ограничениями приватности).
1.2. Виджет «История паспорта»
Тип: таймлайн.
Сущности: Изменения направления, профессии, роли, статуса.
Поля: дата, что изменилось, кто санкционировал, основание.
Действия: фильтр, экспорт.
Доступ: сам участник, СИ, Верификация, Хранители, Архитектор.
1.3. Виджет «Мой ID»
Тип: метка.
Поля: буква волны, 5 цифр, направление, поднаправление.
Действия: копировать, показать QR.
Доступ: все.
1.4. Виджет «Геолокация»
Тип: карта.
Поля: текущая точка, ячейка, зона.
Действия: вкл/выкл, показать свою, показать ячейку.
Доступ: сам, Совет, Балансировка (агрегат), Красный Контур (при режиме).
1.5. Виджет «Статус участника»
Тип: метка.
Поля: Совместим / Условно совместим / Ассоциированный / Полный / На паузе / Вне сети доверия / Мастер / Интегратор / Первопроходец.
Действия: запросить изменение, посмотреть основание.
Доступ: все.
2. Люди и связи
2.1. Виджет «Ячейка»
Тип: дерево.
Сущности: Ячейка N×5, участники, роли.
Поля: уровень, номер, профиль, состав, координатор, ОТК, Хранитель, Связной.
Действия: раскрыть, найти, написать всем, позвонить, массовое сообщение.
Доступ: участники ячейки, Совет, Архитектор.
2.2. Виджет «Поиск участника»
Тип: поиск.
Поля: ID, имя, псевдоним, навык, направление, профессия, ячейка, статус.
Действия: найти, открыть паспорт, написать, позвонить.
Доступ: все.
2.3. Виджет «Наставник и стажёры»
Тип: список.
Поля: наставник, стажёры (до 3), прогресс, дата закрепления.
Действия: открыть паспорт, написать, отчёт.
Доступ: наставник, стажёр, СИ, Совет.
2.4. Виджет «Оценки взаимодействия»
Тип: форма + список.
Поля: надёжность, ясность, этикет, помощь, комментарий.
Действия: поставить оценку, посмотреть свои (не чужие).
Доступ: автор — свои, Балансировка — агрегат, Верификация — по запросу.
2.5. Виджет «Чат»
Тип: чат.
Поля: личный, групповой, канал направления, канал ячейки.
Действия: писать, вложение, упоминание, тред.
Доступ: по роли.
2.6. Виджет «Видео-звонок»
Тип: видео.
Поля: участник, запись, длительность, транскрипт.
Действия: позвонить, записать, сохранить в СИ, пометить.
Доступ: по роли.
2.7. Виджет «Массовое уведомление»
Тип: форма.
Поля: получатели (ячейка, направление, все), тема, текст, приоритет.
Действия: отправить, запланировать, отменить.
Доступ: Совет, Архитектор, Красный Контур.
3. Заявки и онбординг
3.1. Виджет «Форма регистрации»
Тип: форма.
Поля: телефон, мессенджеры, пароль, согласие, источник.
Действия: отправить, отменить.
Доступ: публичный.
3.2. Виджет «Комната ожидания»
Тип: статус.
Поля: статус, таймер, очередь, кнопка «Связаться с СИ».
Действия: отменить, чат, обновить.
Доступ: кандидат.
3.3. Виджет «Список заявок»
Тип: список.
Поля: ID, телефон, мессенджер, дата, статус, источник.
Действия: фильтр, сортировка, открыть, назначить интервью, отклонить.
Доступ: СИ, Архитектор.
3.4. Виджет «Карточка заявки»
Тип: карточка.
Поля: все данные, история, заметки, оценка.
Действия: назначить интервью, отклонить, создать участника.
Доступ: СИ, Архитектор.
3.5. Виджет «Календарь интервью»
Тип: календарь.
Поля: дата, время, кандидат, интервьюер, статус.
Действия: назначить, перенести, отменить, начать.
Доступ: СИ, Архитектор.
3.6. Виджет «Видео-интервью»
Тип: видео.
Поля: кандидат, интервьюер, запись, транскрипт, вопросы.
Действия: начать, записать, пометить, сохранить.
Доступ: СИ, Ноология, Архитектор.
3.7. Виджет «Вопросы интервью»
Тип: список.
Поля: вопрос, категория, кто автор, версия.
Действия: редактировать, добавить, версионировать.
Доступ: Ноология, СИ, Архитектор.
3.8. Виджет «Оценка кандидата»
Тип: форма.
Поля: когнитивный, поведенческий, рефлексивный, технический, рекомендация (направление, профессия, роль), итог (Совместим / Условно / Несовместим).
Действия: сохранить, отправить, создать участника.
Доступ: СИ, Ноология, Архитектор.
3.9. Виджет «Создание участника»
Тип: форма.
Поля: ID (авто), направление, профессия, роль, наставник, приветственный пакет, статус.
Действия: создать, отменить.
Доступ: СИ, Архитектор.
3.10. Виджет «Трекер онбординга»
Тип: прогресс.
Поля: стадии (заявка → интервью → решение → стажировка → основной), срок, статус.
Действия: открыть стадию, заметки.
Доступ: СИ, наставник, Архитектор.
3.11. Виджет «Запрос на смену направления»
Тип: форма + список.
Поля: текущее, желаемое, причина, статус, решение.
Действия: подать, одобрить, отклонить, назначить мини-стажировку.
Доступ: участник, СИ, Совет принимающего направления.
3.12. Виджет «Ассоциированные участники»
Тип: список.
Поля: ID, статус, срок, этап, наставник.
Действия: открыть, продлить, перевести в полный.
Доступ: СИ, Архитектор.
3.13. Виджет «Входная конвертация активов»
Тип: форма.
Поля: тип актива, стоимость, вариант (полная / целевой фонд / внешнее управление), решение.
Действия: подать, одобрить, зафиксировать.
Доступ: участник, Шлюз, Верификация, Хранители.
3.14. Виджет «Модуль Уважение и границы»
Тип: статус.
Поля: пройден/нет, дата, следующий срок.
Действия: записаться, пройти.
Доступ: участник, СИ, Совет.
4. Направления и структура
4.1. Виджет «Карта направлений»
Тип: граф/дерево.
Поля: 17 модулей, статус, совет, стажёры, профессии, роли, режимы.
Действия: открыть, включить/выключить, делегировать.
Доступ: Архитектор, Советы, Балансировка.
4.2. Виджет «Карточка направления»
Тип: карточка.
Поля: номер, название, статус, постоянное/временное, совет, ЗПО (исключительная, разделяемая, смежная), метрики.
Действия: редактировать (Архитектор), открыть совет, открыть профессии.
Доступ: все (чтение), Совет (запись).
4.3. Виджет «ЗПО (Зона профессиональной ответственности)»
Тип: таблица.
Поля: компетенция, тип (исключительная / разделяемая / смежная), направление.
Действия: редактировать, запросить пересмотр.
Доступ: Совет, Балансировка, Архитектор.
4.4. Виджет «Профессии направления»
Тип: список.
Поля: название, компетенции, носители, роли, стаж.
Действия: создать, редактировать, привязать к роли.
Доступ: Совет, Архитектор.
4.5. Виджет «Роли направления»
Тип: список.
Поля: название, тип (постоянная/временная), срок, права, носитель.
Действия: создать, назначить, ротировать.
Доступ: Совет, Архитектор.
4.6. Виджет «Совет направления»
Тип: список.
Поля: члены, мандат, срок, ротация, статус.
Действия: назначить, ротировать, открыть заседание.
Доступ: Совет, Архитектор, Балансировка.
4.7. Виджет «Заседание Совета»
Тип: форма.
Поля: повестка, участники, решения, голоса, протокол.
Действия: созвать, голосовать, зафиксировать, отправить Хранителю.
Доступ: Совет, Хранитель, Архитектор.
4.8. Виджет «Реестр направлений»
Тип: таблица.
Поля: номер, название, тип, статус, дата создания/упразднения.
Действия: фильтр, экспорт.
Доступ: все.
5. Профессии, роли, мандаты
5.1. Виджет «Карта мандатов»
Тип: таблица.
Поля: функция, дом (направление), носитель, срок, условия, статус.
Действия: делегировать, отозвать, продлить, ротировать.
Доступ: Архитектор, Совет, Балансировка.
5.2. Виджет «Делегирование»
Тип: форма.
Поля: функция, кому, срок, условия, права.
Действия: делегировать, отменить.
Доступ: Архитектор, Совет.
5.3. Виджет «Мой мандат»
Тип: карточка.
Поля: функция, срок, условия, статус, история.
Действия: отказаться, передать, продлить (запрос).
Доступ: носитель мандата.
5.4. Виджет «Ротация»
Тип: таймлайн.
Поля: кто, что, когда, кому.
Действия: запланировать, выполнить, отложить.
Доступ: Совет, Балансировка, Архитектор.
5.5. Виджет «Концентрация функций»
Тип: метрика.
Поля: сколько функций у одного лица, риск.
Действия: сигнал, разбор.
Доступ: Балансировка, Верификация, Архитектор.
5.6. Виджет «Эффект холодного периода»
Тип: статус.
Поля: кто, срок, до какого числа.
Действия: проверить, обжаловать.
Доступ: Совет, Балансировка, Архитектор.
6. Ячейки
6.1. Виджет «Дерево ячеек»
Тип: дерево.
Поля: уровень N×5, номер, профиль, состав.
Действия: раскрыть, найти, открыть.
Доступ: все.
6.2. Виджет «Карточка ячейки»
Тип: карточка.
Поля: ID, уровень, состав, координатор, ОТК, Хранитель, Связной, задачи.
Действия: открыть, написать всем, позвонить.
Доступ: участники ячейки, Совет, Архитектор.
6.3. Виджет «Роли ячейки»
Тип: список.
Поля: координатор, ОТК, Хранитель, Связной, Верификатор, Балансировщик, Психоэколог, Ноолог, Инженер Обнуления.
Действия: назначить, ротировать.
Доступ: Совет, Архитектор.
6.4. Виджет «Создание ячейки»
Тип: форма.
Поля: уровень, номер, профиль, состав, родительская ячейка.
Действия: создать, отменить.
Доступ: Совет, Архитектор.
7. Задачи и планы
7.1. Виджет «Дневной план»
Тип: список.
Поля: задача, приоритет, срок, статус, критерии.
Действия: взять, сдать, отчёт.
Доступ: участник, Совет, ОТК.
7.2. Виджет «Карточка задачи»
Тип: карточка.
Поля: ID, тип, дата, номер, описание, требуемые компетенции, локация, приоритет, срок, родительский проект.
Действия: взять, назначить, сдать, отчёт.
Доступ: участник, Совет, ОТК.
7.3. Виджет «Создание задачи»
Тип: форма.
Поля: тип, дата, номер, описание, компетенции, локация, приоритет, срок, проект.
Действия: создать, отправить.
Доступ: Совет, Архитектор.
7.4. Виджет «План реализации»
Тип: карточка.
Поля: ID (PLAN), ожидаемый результат, компетенции, ресурсы, ограничения, критерии приёмки, контрольные точки, условия остановки, ведущее направление, распределение ответственности.
Действия: утвердить, подписать, отправить.
Доступ: Совет, Хранитель, Архитектор.
7.5. Виджет «Структура плана»
Тип: таблица.
Поля: задача, направление, исполнитель, консультант, контролёр, срок, статус.
Действия: редактировать, утвердить.
Доступ: Совет, Хранитель.
7.6. Виджет «Кризисный план»
Тип: карточка.
Поля: сценарий мобилизации, минимальное число, допустимый процент неявки (до 10%), точки сбора, маршруты, графики, критерии прекращения.
Действия: утвердить, активировать.
Доступ: Совет, Красный Контур, Архитектор.
7.7. Виджет «Предварительная материализация»
Тип: статус.
Поля: проект, статус, срок, возражения.
Действия: запустить, приостановить.
Доступ: Совет, Балансировка, Архитектор.
7.8. Виджет «Квант ускорения»
Тип: таймер.
Поля: исходный приоритет, новый дедлайн, статус.
Действия: активировать, отключить.
Доступ: Красный Контур, Стальной Колокол, Архитектор.
8. Сигналы и запросы
8.1. Виджет «Создание сигнала»
Тип: форма.
Поля: описание, обоснование, направления, срок, приоритет, предполагаемый ведущий.
Действия: отправить, сохранить черновик.
Доступ: все.
8.2. Виджет «Карточка сигнала»
Тип: карточка.
Поля: ID (SIG), описание, обоснование, направления, приоритет, статус, итерации, ведущий.
Действия: открыть, ответить, эскалировать.
Доступ: все.
8.3. Виджет «Входящие сигналы»
Тип: список.
Поля: ID, тема, приоритет, срок, статус, инициатор.
Действия: фильтр, ответить, назначить ведущего.
Доступ: Совет, Связной, Архитектор.
8.4. Виджет «Всеобщий прогон»
Тип: таблица.
Поля: направление, ответ, обоснование, срок.
Действия: ответить, посмотреть агрегат.
Доступ: Совет, Архитектор.
8.5. Виджет «Коннект»
Тип: форма.
Поля: предмет, позиции, причина, способы устранения, результат.
Действия: запустить, зафиксировать, эскалировать.
Доступ: Совет, Ноология, Когнитивная Логистика.
8.6. Виджет «Арбитраж»
Тип: карточка.
Поля: процедурный вопрос, стороны, решение, срок.
Действия: подать, рассмотреть, вынести.
Доступ: Арбитраж, Жюри, Архитектор.
8.7. Виджет «Лимит итераций»
Тип: метрика.
Поля: запрос, число возвратов, лимит (3), статус.
Действия: эскалировать.
Доступ: Балансировка, Связной, Архитектор.
8.8. Виджет «Атрибуты потока»
Тип: таблица.
Поля: скорость, формат, этикет, приоритет.
Действия: посмотреть, обжаловать.
Доступ: Совет, Балансировка.
8.9. Виджет «Отсутствие влияния»
Тип: метрика.
Поля: направление, процент, категории.
Действия: сигнал, разбор.
Доступ: Балансировка, Верификация, Архитектор.
8.10. Виджет «Смена ведущего»
Тип: метрика.
Поля: тип задачи, ведущие, частота.
Действия: сигнал, пересмотр ЗПО.
Доступ: Балансировка.
9. Отчёты и ОТК
9.1. Виджет «Фото-отчёт»
Тип: загрузка.
Поля: задача, фото, комментарий, геометка, время.
Действия: загрузить, отправить.
Доступ: исполнитель.
9.2. Виджет «Видео-отчёт»
Тип: загрузка.
Поля: задача, видео, комментарий, геометка, время.
Действия: записать, загрузить, отправить.
Доступ: исполнитель.
9.3. Виджет «Очередь ОТК»
Тип: список.
Поля: задача, исполнитель, отчёт, статус, срок.
Действия: принять, вернуть, прокомментировать.
Доступ: ОТК, Совет, Верификация.
9.4. Виджет «Приёмка»
Тип: форма.
Поля: критерии, результат, решение, комментарий.
Действия: принять, вернуть, эскалировать.
Доступ: ОТК.
9.5. Виджет «Критерии приёмки»
Тип: список.
Поля: название, описание, версия, дата публикации.
Действия: редактировать (до начала цикла), публиковать.
Доступ: Совет, ОТК.
9.6. Виджет «Апелляция ОТК»
Тип: форма.
Поля: задача, причина, решение Совета.
Действия: подать, рассмотреть.
Доступ: исполнитель, Совет.
9.7. Виджет «Статистика ОТК»
Тип: график.
Поля: процент брака, время проверки, динамика.
Действия: фильтр, экспорт.
Доступ: Балансировка, Совет, Архитектор.
9.8. Виджет «Независимая перепроверка»
